# Chuong Le Portfolio

A responsive React portfolio built with Vite, Tailwind CSS, Framer Motion, and Lucide.

## Run locally

```powershell
npm install
npm run dev
```

Vite prints the local development URL after startup.

## Production build

```powershell
npm run build
npm run preview
```

## Personalize before publishing

- Add real `repository` and `demo` URLs to each project object in `src/App.jsx`.
- Replace the GitHub and LinkedIn profile links in the contact section with your profile URLs.
- The resume button opens the browser print dialog; choose **Save as PDF** to download a PDF.
- The contact form opens the visitor's email application with a pre-filled message; it does not send or store submissions.

The project filter, theme preference, mobile navigation, role rotator, accessible motion, and print-friendly resume view work without a backend.
